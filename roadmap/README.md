# Python Certification Roadmap

**Established:** 2026-10-10  
**Current status:** Planned; no exam pass or enrollment claimed.

## Credential sequence (Python Institute / OpenEDG)

### PCEP — Certified Entry-Level Python Programmer

First checkpoint. Be able to explain and use variables, fundamental data types, operators, input/output, branching, loops, and functions. Write short programs from an unfamiliar problem statement instead of memorizing examples.

**Evidence before exam booking:** complete a range of original small exercises, debug mistakes, and explain the code aloud or in writing.

### PCAP — Certified Associate Python Programmer

Second checkpoint. Build comfort with modules, exception handling, strings, file-oriented tasks, and object-oriented programming. Understand program structure beyond single-purpose scripts.

**Evidence before exam booking:** produce independently tested programs with multiple functions or modules, usable error messages, and recorded test cases.

### PCPP1 — Certified Professional Python Programmer Level 1

Advanced target. Study the published official syllabus when ready; prepare with projects demonstrating deeper program structure, best practices, and reliable operation.

**Evidence before exam booking:** build and maintain a more substantial Python application, review design tradeoffs, and verify the then-current official exam objectives.

Official Python Institute certification track: https://pythoninstitute.org/certification-tracks

**Verification note:** Certification branding, availability, syllabus, passing criteria, and costs can change. Consult the official provider before scheduling. Python certification is not a required prerequisite for RHCSA, RHCE, or Azure exams.

## Learning order

1. **Reading code:** understand syntax, names, types, branches, loops, and functions.
2. **Writing code:** translate a requirement into a small working program.
3. **Operating in Linux:** use the shell, files, paths, permissions, subprocesses, and safe error handling.
4. **Automation:** inventory, monitoring, reporting, and reproducible tasks.
5. **Integration:** connect Python practice to Baby Cloud and later Azure without assuming services are already deployed.
6. **Certification:** validate readiness against current official objectives.

## Definition of done for an exercise

- State the objective in one sentence.
- Record environment, Python version, and requirements.
- Save the source and describe the commands used.
- Execute the program and preserve relevant output or test evidence.
- Explain one failure or edge case and how it was handled.
- Record what was learned without claiming unperformed testing.

## Coordination with other tracks

- **RHCSA/RHCE:** Do not divert urgent NOS-120 or RHCSA study time to chase Python credentials.
- **Baby Cloud:** Keep operational cluster scripts in its own repository. Link to a Python learning exercise when it becomes useful infrastructure.
- **Azure:** Plan Azure certification work independently; Python may later support cloud administration.

Begin structured fundamentals after urgent Linux course milestones, with a tentative goal of progressing through PCEP and PCAP during the degree program and evaluating PCPP1 by 2029. These dates are aspirations, not commitments or certification records.
